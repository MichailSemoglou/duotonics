# Security policy

## Supported versions

Security fixes are applied to the latest release on `main`. Update to the latest released version before reporting an issue.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/MichailSemoglou/duotonics/security/advisories/new). Do not open a public issue for a vulnerability that has not been resolved.

Include the affected version, operating system, reproduction steps, potential impact, and any suggested mitigation. Reports are reviewed by the repository owner, who will coordinate validation, remediation, and disclosure.
